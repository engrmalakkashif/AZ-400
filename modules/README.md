# AZ-400 Modular Course

Each module is a separate lesson file with **Lesson Notes**, **Lab Notes**, **Exercises**, and **Verification**. The objective map follows the outline supplied for the English exam updated July 27, 2026.

## Exam at a Glance

| Item | Detail |
|---|---|
| Exam | AZ-400: Designing and Implementing Microsoft DevOps Solutions |
| Credential | Microsoft Certified: DevOps Engineer Expert |
| Questions | Approximately 40–60; multiple choice, multi-select, drag-and-drop, hot-area, case studies, and labs may appear |
| Duration | Approximately 120 minutes |
| Passing score | 700 / 1000 |
| Cost | Approximately $165 USD; varies by region |
| Validity | 1 year; free renewal assessment on Microsoft Learn |
| Expert prerequisite | AZ-400 can be taken alone; the Expert badge requires an active AZ-104 or AZ-204 |

Confirm current exam logistics, price, eligibility, and objectives on Microsoft's official exam page before scheduling.

Official references: [AZ-400 exam page](https://learn.microsoft.com/en-us/credentials/certifications/exams/az-400/) and [AZ-400 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-400).
